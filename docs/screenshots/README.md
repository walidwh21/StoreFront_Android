# Screenshots

The images in this folder are **layout previews**, not captures from a device.

To replace them with real screenshots, run the app on an emulator, then:

```bash
adb exec-out screencap -p > docs/screenshots/catalog.png
```

Keep these file names so the main README keeps working:
`catalog`, `product-details`, `cart`, `checkout`, `sign-in`, `sign-up`, `orders`,
`order-details`, `profile`, `admin`, `stock-management`, `user-management`.
